# mp2d-web
Ceci est le répertoire officiel du jeu Meatball Party 2D, pour le web. Alimenté par Unity Engine.
Pourquoi ce repo existe ? Par ce que, j'ai trouvé ça drôle de faire tourner un jeu sur le web ＜（＾－＾）＞.


Pour télécharger le jeu, avoir plus d'infos sur MeatBall MC, ou rejoindre l'équipe, jette un coup d'oeil sur meatball-mc.fr
